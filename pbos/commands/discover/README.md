# PBOS Discover Command

> Describe your organization. We'll engineer the platform.

═══════════════════════════════════════════════════════════════════════════════

## Purpose

The Discover Command is the constitutional entry point into PBOS Genesis.

It launches an executable Discovery Session capable of understanding an
organization through guided interaction, organizational documents, existing
software repositories, or a hybrid acquisition strategy.

The Discover Command SHALL initialize the complete Constitutional Discovery
Runtime and produce a certified Discovery Report suitable for organizational
compilation.
