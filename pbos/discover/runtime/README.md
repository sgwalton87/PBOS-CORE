# PBOS Discovery Runtime

> Constitutional Discovery is an executable runtime.

═══════════════════════════════════════════════════════════════════════════════

## Purpose

The Discovery Runtime executes Constitutional Discovery.

The Runtime governs:

• Discovery Sessions

• Runtime Context

• Runtime State

• Pipeline Execution

• Recovery

• Metrics

The Runtime SHALL remain deterministic.

The Runtime SHALL preserve constitutional lineage.

═══════════════════════════════════════════════════════════════════════════════

## Constitutional Principle

Discovery SHALL execute through the Runtime.

Discovery SHALL NOT execute directly from adapters.
