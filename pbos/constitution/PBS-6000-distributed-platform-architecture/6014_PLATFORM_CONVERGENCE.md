# Platform Convergence

PBOS continuously converges declared intent with observed platform truth:

1. Load the application blueprint and constitutional graph.
2. Resolve exact repository and environment identities.
3. Collect current evidence from each required node.
4. Evaluate dependencies in topological order.
5. Emit telemetry for healthy, degraded, failed, blocked, and unknown nodes.
6. Remediate only deterministic, authorized, bounded differences.
7. Stop at protected actions or non-deterministic decisions.
8. Revalidate the changed node and every downstream dependent.

Convergence may repair configuration drift. It may not manufacture evidence, bypass approval, or report completion while a required node or journey is unproven.
