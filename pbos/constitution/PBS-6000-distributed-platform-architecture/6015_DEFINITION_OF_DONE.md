## Executable definition of done

A functional application mission is done only when:

- the constitution and blueprint resolve without conflict;
- repository dependencies install reproducibly from a committed lockfile;
- PBOS execution and evidence lineage identify the exact commit;
- required data, identity, secrets, and declared providers are healthy in the tested environment;
- the application launches and responds to runtime probes;
- desktop and mobile browser journeys execute against durable data and authority boundaries;
- accessibility and security acceptance evidence passes;
- telemetry and artifacts are recorded without secret leakage;
- any required preview or production URL serves the exact validated revision;
- PBOS Kernel advances the mission to human certification readiness.

For production release, Vercel, DNS/TLS, email, observability, and all declared external services must also be healthy. “Command returned zero,” “files generated,” “PR opened,” and “CI green” are intermediate evidence, never functional completion by themselves.
