# Google Cloud Architecture

Google Cloud owns OAuth configuration, enabled APIs, IAM, service accounts, Google integrations, and PBOS-hosted runtime resources where declared. PBOS shall validate project identity, API enablement, least-privilege bindings, callback alignment, service health, and exact deployed image lineage.

Google Cloud is not a duplicate application database or a substitute for PBOS execution state. Protected mutations require the applicable approval boundary.
