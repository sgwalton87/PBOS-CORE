# Purpose

Testing governs engineering confidence.

Testing supports functional truth.

Testing does not replace functional truth.

---

# Required Test Categories

PBOS shall execute:

Unit Tests

Integration Tests

API Tests

Database Tests

Browser Tests

Accessibility Tests

Performance Tests

Security Tests

Acceptance Tests

Regression Tests

# Test Failures

Test failures generate autonomous repair missions.

Repeated failures shall trigger governed stopping conditions.

---

# Constitutional Rule

Passing tests alone shall never certify product capability.

---

# Definition of Done

Testing continuously supports autonomous software production.
