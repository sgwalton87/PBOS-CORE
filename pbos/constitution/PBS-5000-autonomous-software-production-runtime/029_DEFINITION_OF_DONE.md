# Purpose

This document establishes the constitutional Definition of Done governing autonomous software production throughout PBOS.

Engineering completion shall never be confused with product completion.

Completion is determined by verified functional capability.

---

# Engineering Completion

Engineering completion includes:

- Source code implemented
- TypeScript passes
- Lint passes
- Unit tests pass
- Integration tests pass
- Documentation updated
- Repository validation succeeds

Engineering completion supports production.

Engineering completion is not production.

---

# Functional Completion

Functional completion requires:

- Application launches
- Runtime is healthy
- APIs respond correctly
- Database persists correctly
- Browser journeys execute successfully
- Accessibility validation succeeds
- Security validation succeeds
- Functional acceptance succeeds
- Required evidence exists

Functional completion precedes certification.

---

# Certification Requirements

A Product Node may become CERTIFIED only when:

Engineering validation succeeds.

Runtime validation succeeds.

Journey validation succeeds.

Acceptance validation succeeds.

Accessibility validation succeeds.

Security validation succeeds.

Required evidence exists.

No release-blocking regression exists.

Dependency integrity is preserved.

Product health remains acceptable.

---

# Autonomous Completion

PBOS shall continue autonomous execution until:

The current mission is functionally complete.

OR

A governed stopping condition exists.

PBOS shall not terminate because:

- Code compiled
- Pull request merged
- Tests passed
- Reports generated
- Documentation updated

These are engineering milestones.

Not completion.

---

# Constitutional Definition of Done

PBOS has completed its mission only when:

A real user can successfully perform the intended workflow using verified executable software.

This workflow has been validated through runtime execution.

The workflow satisfies its Acceptance Contract.

Evidence has been collected.

Certification has been granted.

The Product Graph has been updated.

Mission Intelligence has selected the next executable mission or identified a valid constitutional stopping condition.

---

# Final Constitutional Statement

PBOS exists to build working software.

Working software exists to empower people.

Engineering exists to serve working software.

Working software—not engineering activity—remains the constitutional objective of PBOS.

---

# Definition of Done

PBS-5000 is complete when every autonomous engineering capability inherits this constitutional definition of completion.
