# Purpose

Mission Control provides complete operational visibility into PBOS.

Mission Control is the founder's operational console.

It is not a reporting dashboard.

---

# Mission Control Responsibilities

Mission Control shall display:

Current Mission

Current Journey

Current Product Node

Current Runtime

Current Browser

Current Route

Current Runtime Health

Current Product Health

Current Acceptance Status

Current Repair

Current Certification

Current Screenshots

Current Logs

Current Metrics

Current Elapsed Time

Current Queue

Current Next Mission

---

# Runtime Source

Mission Control shall consume Runtime State.

Mission Control shall not calculate independent state.

Mission Control shall not maintain duplicate execution state.

---

# Constitutional Rule

Mission Control reflects PBOS.

Mission Control never invents PBOS.

---

# Definition of Done

Mission Control exposes complete live operational awareness.
