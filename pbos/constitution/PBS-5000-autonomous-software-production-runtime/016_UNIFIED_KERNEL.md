# Purpose

The Unified Kernel establishes one canonical execution authority for PBOS.

Every autonomous subsystem shall execute through the PBOS Kernel.

---

# Kernel Responsibilities

The Kernel owns:

Repository Intelligence

Product Intelligence

Journey Intelligence

Mission Intelligence

Execution Planning

Engineering

Compilation

Runtime

Browser Runtime

Acceptance Runtime

Repair Runtime

Evidence Runtime

Certification

Mission Continuation

Mission Control

---

# Single Runtime Authority

Exactly one runtime authority shall exist.

Duplicate runtime state is prohibited.

Duplicate mission state is prohibited.

Duplicate completion authority is prohibited.

---

# Single Execution Pipeline

Every mission shall execute through:

Repository Intelligence

↓

Mission Intelligence

↓

Planning

↓

Engineering

↓

Runtime

↓

Acceptance

↓

Repair

↓

Certification

↓

Continuation

No alternate execution path is permitted.

---

# Constitutional Rule

Every subsystem shall inherit Kernel authority.

Subsystems shall never independently determine completion.

---

# Definition of Done

The PBOS Kernel becomes the single execution authority for autonomous software production.
