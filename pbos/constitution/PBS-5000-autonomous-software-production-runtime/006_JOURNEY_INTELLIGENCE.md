# Purpose

Journey Intelligence governs complete user workflows.

PBOS shall optimize complete experiences rather than isolated features.

---

# Journey Definition

A Journey is a complete sequence of user interactions resulting in meaningful value.

Journeys span multiple Product Nodes.

---

# Supported Journeys

Examples include:

- Scholar Journey
- Scholar Athlete Journey
- Parent Journey
- Mentor Journey
- Teacher Journey
- Counselor Journey
- Coach Journey
- Employer Journey
- Founder Journey
- Administrator Journey

Future journeys inherit this architecture.

---

# Journey Steps

Every Journey Step shall define:

- Identifier
- Inputs
- Outputs
- Required UI
- Required APIs
- Required Database State
- Permissions
- Acceptance Contract
- Evidence Requirements
- Dependencies

---

# Journey Health

Journey Health shall report:

- COMPLETE
- PARTIAL
- BLOCKED
- FAILED
- REGRESSION

PBOS shall prioritize restoring broken journeys before implementing unrelated features.

---

# Definition of Done

PBOS continuously reasons about complete user workflows.
