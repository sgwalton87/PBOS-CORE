# PBOS Constitutional Discovery Prompts

Purpose

This directory contains governed prompt contracts used by the Constitutional
Discovery Engine.

Prompts are implementation artifacts.

They SHALL NOT define constitutional authority.

Authority remains exclusively within the PBS-DSC Constitutional Domain.

Prompt responsibilities include:

• Founder interviews

• Organizational discovery

• Clarification requests

• Evidence collection

• Organizational modeling

• Discovery summarization

• Recommendation generation

All prompts SHALL preserve founder intent, constitutional governance, and
organizational truth.

PBOS SHALL NEVER fabricate organizational knowledge.
