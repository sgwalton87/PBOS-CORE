# PBOS Constitutional Mission Planner

> Every organization already knows what it needs.

> PBOS discovers the work.

═══════════════════════════════════════════════════════════════════════════════

## Purpose

The Constitutional Mission Planner transforms the Canonical Organization Model
into a deterministic Mission Queue.

Mission Planning SHALL determine the constitutional engineering work required
to realize an organization's platform.

The Mission Planner SHALL discover work.

It SHALL NOT invent work.
