# PBOS Compiler Pipeline

## Purpose

The Compiler Pipeline coordinates the complete Organizational Engineering
Compiler.

Individual engines SHALL NOT invoke one another directly.

All compiler stages SHALL execute through the Compiler Pipeline.

---

## Responsibilities

• Manage execution stages

• Preserve compiler context

• Enforce execution ordering

• Track evidence lineage

• Produce pipeline reports

• Coordinate runtime lifecycle
