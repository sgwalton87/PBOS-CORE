# PBOS Genesis Logo Assets

`pbos-genesis-master-brand-board.png` is the supplied 1536 × 1024 RGB master reference board for PBOS Genesis.

SHA-256: `b5b1421bb393a77dc0d737b9318e2f1563df05d6f5443b58c7a8d67c02b43fd3`

The board documents the full lockup, horizontal lockup, mark, stacked lockup, monochrome treatments, and app-icon concept. It is not a transparent production export. Before public launch, create approved SVG masters and transparent PNG exports for every lockup and validate them against the brand contract.

The current hexadecimal UI palette is a visual approximation derived from the raster board. A brand owner must approve it or replace it with the original design-source values before certification.

PBOS Genesis is the factory brand. Playbook Platform is an independent application brand and must have its own logo files, icon, palette, store artwork, and design card.
