## Governance Assertions

- Application repositories retain ownership of domain code and product behavior.
- PBOS Core contains provider-neutral contracts, adapters, registries, and orchestration APIs.
- Cross-system mission and intelligence requests fail closed.
- High-risk autonomous work requires explicit human approval.
- Repository promotion requires completed work, passing evidence with matching lineage, and formal certification.
- No Playbook Platform or Bulletproof Beneficiary product logic is embedded in PBOS Core.

## Reference Systems

- Playbook OS → Playbook Platform
- Bulletproof OS → Bulletproof Beneficiary

Both reference systems use the same PBOS v1 foundation while remaining independently governed applications.
