# Constitutional Engineering Compiler (CEC)

> "The Planner determines **what** shall be engineered.
>
> The Compiler determines **how** constitutional engineering becomes
> implementation-ready engineering."

═══════════════════════════════════════════════════════════════════════════════

## Purpose

The Constitutional Engineering Compiler (CEC) is the transformation engine of
PBOS Genesis.

Unlike traditional compilers that translate programming languages into machine
instructions, the CEC transforms governed organizational engineering into
implementation-ready engineering.

The Compiler preserves constitutional meaning while producing deterministic,
implementation-independent engineering packages.

The Compiler never becomes the source of truth.

The Constitution remains the source of truth.
